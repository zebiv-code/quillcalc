# QuillCalc

A web-based clone of VisiCalc, the revolutionary spreadsheet program from 1979. Features a terminal-style interface with keyboard-driven navigation, formula engine with dependency tracking, and classic slash commands.

**[Live Demo](https://zebiv.com/quillcalc/)**

## Features

- 63 columns (A-BK) x 254 rows grid
- Formula engine with @SUM, @AVERAGE, @COUNT, @MIN, @MAX, @IF
- Automatic recalculation with dependency graph
- VisiCalc slash commands (/B, /C, /D, /E, /F, /G, /I, /M, /R, /S, /T, /W)
- Undo/redo support
- Terminal-style green phosphor display
- Keyboard-only navigation (arrow keys, no mouse)

## Tech

- Vanilla HTML/CSS/JavaScript
- No dependencies, no build step
- IBM Plex Mono font via Google Fonts
